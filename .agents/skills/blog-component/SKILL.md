# 博客交互组件

## 先确定范围

1. 读取 [设计约定](references/design.md)，按组件类型选择文件：
   - 参数实验、计算器、图解面板：读取 [基础样式](assets/component.css)，按需参考 [折射示例](examples/refraction.html)。
   - A/B 图片滑动对比：读取 [图片对比约定](references/image-compare.md)、[独立样式](assets/image-compare.css)、[交互脚本](assets/image-compare.js) 和 [示例](examples/image-compare.html)。不要加载面板样式。
2. 按用户要求确定输入、输出、计算关系和必要操作；不要因为示例中有某种控件就全部添加。
3. 示例只说明组合方式。沿用用户的图片、caption、公式、变量名、语言、默认值和精度；不把示意素材当作用户内容。
4. 无法确认的图片对齐条件、物理或算法条件先说明，不捏造计算结果。

路径均相对于本 skill 目录。仓库根位于 `../../..`。规则以本 skill 和用户当前要求为准，不需要读取临时风格比较页。

## 默认只输出组件本体

图片对比默认只有 `figure → 图片与中央滑杆 + figcaption`，左 A、右 B，无面板边框、圆角、阴影或额外控件。

参数实验等面板组件由下列区域按需组合：

```text
面板
├── 顶栏：分段导航 / 当前模式（可选）
├── 主区域：图解、画布、表格或计算结果
├── 参数区：滑杆、下拉框、数值输入（按需）
├── 操作区：开关、重置、记录等（按需）
├── 结果栏：数值与单位（可选）
└── 状态栏：验证、错误、操作反馈（可选）
```

默认**不要出现**：

- 组件外的可见标题、导语、文章背景介绍；
- 品牌栏、风格选择器、宽度切换器、配色表、设计参数侧栏；
- 原理说明卡片、源码展示、页脚、版权标语；
- 口号、装饰性英文、比喻标题、无用途编号。

必要的图例、变量、单位、字段标签、错误说明和无障碍名称必须保留。文档 `<title>`、SVG `<title>/<desc>` 不属于应删除的装饰文本。原理说明或代码展示只有用户明确要求时才添加。

## 复用方式

- 面板组件从 `assets/component.css` 选择需要的类和变量；图片对比使用独立的 `image-compare.css` / `image-compare.js`，不引入完整 UI 框架。
- 面板颜色使用 `.kc-root` 中的语义变量；图片对比使用 `.kc-compare`，不套用面板边框、内阴影和外层留白。领域图形的颜色与坐标放在组件自己的样式和脚本中。
- `.kc-*` 是普通 HTML/CSS 作者约定，**不是插件 API**。宿主不会注入这些类或变量。
- 示例用相对 `<link>` / `<script src>` 引用共享资源，只为在仓库内直接打开并复用同一份文件。
- 交付可粘贴的组件或自包含临时 HTML 时，默认将 CSS/JS 内联；图片路径相对于目标文章或笔记。不能让产物依赖 `.agents/skills` 路径。用户明确要求共用资源时，将资源放在目标内容目录或 Vault 可解析的位置。裁剪无关的样式、示例业务和控件。
- 字体族为系统无衬线与 `"JetBrains Mono", monospace`。不默认加载网络字体；不能声称沙箱继承了博客字体。

## HTML 与交互

- 优先使用原生 `button`、`input`、`select`、`output`、`table`；按钮声明 `type="button"`，字段绑定 `label`。
- 分段导航只在确有多个视图时使用。实现 `tablist` / `tab` / `tabpanel`、选中态、焦点顺序及左右键、Home、End。
- 输入事件重算真实结果与图形。数值无效时给出关联错误提示，暂停依赖有效参数的操作；不得展示 NaN、Infinity 或静默篡改输入。
- 指标保留单位；图解的箭头、角度、点位与数据同步。用文字或线型补充颜色区分。
- 重置、采样上限、清空范围和保存周期必须可预测。示例记录只在内存中保存，不应扩展成隐式持久化。
- 使用 IIFE 或局部作用域。对动态文本使用 `textContent`，不要插入未经处理的 HTML。
- 新增动画时提供暂停或停止方式，尊重 `prefers-reduced-motion`；不添加无功能的自动动画。

## 嵌入限制

交付 Markdown 时，使用一个完整的围栏：

````markdown
```html component
<!-- 内联样式、组件本体和经典脚本 -->
```
````

- 标记是区分大小写的完整 `html` 和 `component` token。不要改成新语法。
- 每个组件在独立的 `sandbox="allow-scripts"` iframe 中运行。不要请求 `allow-same-origin` 或依赖宿主 DOM、Cookie、localStorage、Obsidian API。
- 默认内联 CSS、经典 JS 和 SVG，不默认依赖 CDN、模块脚本、网络请求或外部资源。
- body 透明、无外边距；背景只设置在组件面板上。内容驱动高度，不用 `100vh`、固定 iframe 高度或依赖父级高度的百分比布局。
- 自动高度由博客/插件注入的运行时处理。组件不自行创建 iframe，不复制主题选择/高度消息协议。
- CSS `url()`、JS import/fetch 字符串等不会自动按笔记路径重写；确需资源时先按当前项目契约确认加载方式。

## 验证与交付

1. 在普通浏览器预览，再在仅允许脚本的 iframe 中验证内联后的版本。
2. 检查 740px、375px，必要时 320px：不出现页面横向溢出，控件纵向重排，不整体缩小文字。
3. 按组件类型测试：面板检查输入边界、无效值、重置、视图和记录；图片对比检查左右关系、0/50/100% 裁剪、鼠标/触摸/键盘、加载失败和多实例。只测试本组件实际提供的功能。
4. 检查键盘焦点、字段标签、无效提示、禁用态，以及内容增长和收缩。不要为了测试新增生产接口。
5. 确认没有外层标题/说明/代码展示、未使用的主题和示例功能，没有资源或脚本错误。
6. 用户要代码时直接给完整围栏；要文件时给文件路径。未实际做的验证不要写成已通过。

只修改用户指定的文章或组件文件。不得顺手修改全局主题、插件、依赖、无关文章，或提交工作区已有变更。
