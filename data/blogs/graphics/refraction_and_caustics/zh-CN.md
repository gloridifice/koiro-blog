| ------ | ------- | ------- |

# 一、快速近似

## 折射

折射的近似方法是根据深度和水面法线来计算屏幕空间 uv 偏移，然后采样屏幕空间纹理。

相机指向水面片源的向量为 $\mathbf I$ （view），经过水面折射计算后的折射方向为 $\mathbf R$（refract）
可以使用 WGSL 的 `refract` 函数结合水面法线和折射率直接计算（折射率是用户参数，默认为水的 1.33）：
$$
\mathbf R = refract(\mathbf I, \mathbf N, \frac{1}{n_{water}})
$$
接着，我们想要求射线 $\mathbf R$ 与场景的交点。我们将场景近似为一个平面，平面的深度 $h$ 为 “当前水面片源的世界高度 - 同屏幕位置的场景不透明物体的世界高度”：
$$h = max(P_{water}^y - P_{opaque}^y, 0)$$
然后计算平面到深度为 $h$ 的交点 $\mathbf Q$：

```
P（水面上的入水点）
│╲ θ
│  ╲
│    ╲  t（沿折射光线走的距离）
│      ╲
└────────Q（估算落点）── 假设的水平底面
↕
h 是 P 到底面的竖直高度差
```
$$
t = \frac{h}{\cos\theta}=\frac{h}{max(-R_y, 0.15)},\qquad \mathbf Q=\mathbf P_{water}+t\mathbf R
$$
因为 $\mathbf R$ 是单位向量，所以其 y 直接等于 $\cos\theta$。0.15 是为了防止视角过于倾斜，采样过远，更容易出现未命中的情况，见下文。

然后将落点 $\mathbf Q$ 变换到屏幕 uv 空间，就得到我们要采样的 uv 了。由于 $\mathbf Q$ 在世界空间，我们用视图矩阵变换 + 透视除法得到 NDC 位置，然后映射到屏幕 uv 空间就可以。为了让透视效果更可控，我们想要提供给用户一个透视偏移强度系数（默认为 1.0），用 $w$ 表示。

我们先计算落点和实际位置在屏幕空间的差值，然后乘以 $w$，然后再重新计算 uv，公式表达就是：
$$
UV_{\rm sample}=UV_P+w\,(UV_Q-UV_P)
$$
对于超出屏幕范围的，即 uv 超出 0 到 1 的采样点，我们视为未命中位置。同时，高出水面的位置也被视为未命中位置，这些位置不在水中，当然不能作为折射颜色。我们同时比较屏幕深度和世界高度来判断一个位置是否在水中。对于未命中位置，我们直接使用原本的 uv，不进行偏移，无折射效果。

# 二、物理方法

## 折射

物理方法的折射只是不使用近似屏幕来求交，而是使用屏幕空间射线追踪找到真正的交点。和 SSR 类似。应用于 SSR 的优化方案亦可以使用在这个方法中。

最常见的方案是 Hierarchical Z（Hi-Z），其思想是将屏幕空间分块，每块记录当前块最小和最大深度。我们保存不同尺寸的分块记录，形成一个类 mipmap 的金字塔结构。要查询某个屏幕空间位置是否相交的时候，我们先去最上层的最小的金字塔，让射线经过它所处的分块。如果射线的深度从 0.7 变到 0.3，而块的深度为 0.81 - 0.85，说明射线和块完全错开，跳过该块。反之，如果深度有重合我们采样更细的块，重复本操作，直到到像素层。像素层通过射线深度和像素深度做差，小于一定容差，我们就认为命中。

我们的步进预算是 128，也就是最多查询 128 个块，超过该数认为未命中。

现代的 GPU 大都支持硬件 Hi-Z，不过其只能用于 Hi-Z 剔除，并不能用于我们的射线步进。

## 焦散

物理上，焦散是因为水表面方向不一，折射的光在某些位置汇聚在一起，看起来更亮，而产生的图案。

在实践上，我们用类似的方法做快速求交，不过可以利用 GPU 并行。我们仍然使用二维网格来分化水平空间。假想我们有一个 256x256 的网格。

1. Compute pass：根据水面法线，对水体每一个网格进行折射计算，并记录偏折的方向打到的实体上（对应复杂物体可以使用高度场）。
2. 顶点着色器：顶点着色器并不使用索引绘制，而是使用顶点序号计算需要读取的顶点坐标，并且读取三角形的三个顶点。然后采样网格对顶点进行偏移，然后计算三角形面积，用面积计算亮度（面积越小，意味着光线越聚集，亮度越大）。然后，再将顶点变换到 x z 平面上，这样可以渲染出世界空间俯视向下的纹理，用于后续 pass。
3. 片源着色器：将亮度写到焦散纹理上。
4. 海底着色：使用 x z 坐标采样焦散纹理，自行着色。

使用一个网格缓存，Compute pass 预计算，可以让顶点复用求交结果，从而减少计算量。
