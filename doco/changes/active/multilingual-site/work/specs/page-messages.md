# 页面文案字典与语言上下文

## Scope and current contracts

本文件是目标规格，不代表当前站点已支持字典。

当前导航、首页、关于页、分页及无障碍标签的文案分散在 [KoiroCatCafe.kt](../../../../../../src/main/kotlin/KoiroCatCafe.kt)、[Configs.kt](../../../../../../src/main/kotlin/htmlgen/Configs.kt)、[page](../../../../../../src/main/kotlin/htmlgen/page/)、[component](../../../../../../src/main/kotlin/htmlgen/component/)；RSS 描述及语言也在生成器中固定。[当前架构](../../../../../architecture.md)尚无已记录契约，当前 specs 尚无相关条目。

本规格约束页面文案和参数格式化。文章译本不放入页面字典，见 [内容规格](content-localization.md)。

## Requirements

### M1. 语言配置与字典文件

目标组织：

```text
i18n/
  locales.toml
  zh-CN.toml
  en-US.toml
```

语言配置区分默认访问语言、基础字典和内容回退：

```toml
default = "en-US"
base = "zh-CN"
content-fallbacks = ["en-US", "zh-CN"]

[locales.en-US]
name = "English"
language = "en"
match-default = true

[locales.zh-CN]
name = "简体中文"
language = "zh"
script = "Hans"
match-default = true
```

- `default` 决定根入口没有可用偏好时的语言，不决定文案缺失的回退来源。
- `base` 为 `zh-CN`，其字典是页面文案键及参数的校验基准。
- `content-fallbacks` 只用于正文译本，不用于页面文案查找。
- 新语言通过注册信息、语言字典和按需提供的内容译本接入，不要求逐个修改页面组件。
- 执行时提取完整中文字典，并创建仅带注释的空英文字典，不进行英文文案翻译；英文页面按规则显示中文回退文案。

### M2. 字典边界与格式

字典使用 TOML，按语义分组，键名不依赖当前显示文案。例如：

```toml
[nav]
home = "主页"
blogs = "博客"
portfolio = "项目"
about = "关于"

[pagination]
previous = "上一页"
next = "下一页"
page = "第 {page} 页"
summary = "第 {first}–{last} 条，共 {total} 条"

[translation]
activeAi = "本动态由 AI 自动翻译为{contentLanguage}。"
activeFallback = "本动态无{requestedLanguage}，自动回退到{contentLanguage}。"
articleAi = "本文章由 AI 自动翻译为{contentLanguage}。"
articleFallback = "本文章无{requestedLanguage}，自动回退到{contentLanguage}。"
aiLabel = "AI 翻译"
```

字典涵盖导航、按钮、分页、无障碍标签、页面标题、首页与关于页介绍、分类和状态名称、RSS 说明、缺译与 AI 翻译提示。

文章标题、摘要、正文、项目简介及图片说明保留在语言 Markdown。技术标签、品牌和人名不因启用语言系统就自动翻译。友情链接名称作为专名保留；描述按稳定的友链标识提取到中文字典，英文仍回退中文。

完整句子使用命名参数，不拼接多个翻译片段来固定语序。其他语言可重排参数，但必须与基础文案使用相同的参数集合。

字典提供普通文本，不任意嵌入 HTML；链接等结构由页面组件生成，文本与参数在输出时转义。

### M3. 查找与校验

- 页面文案按“目标语言键 → 中文基础键”查找，不经过英文中转。
- 中文基础字典必须包含所有使用中的键；缺少时构建失败，即使某个非中文字典提供了该键。
- 非中文缺少键时使用中文并输出构建警告，警告能定位语言与键。
- 已提供译文的参数集合与中文基准不一致时构建失败；不是当作缺译静默回退。
- 渲染调用缺少所需参数时构建失败，避免发布 `{page}` 等未替换占位符。
- 语言配置和 TOML 格式错误须在构建期报告，不能发布半解析的文案。
- 已注册语言缺少非基础字典文件时按空字典处理并警告；基础字典文件缺失或任一存在的字典 TOML 无效时构建失败。中文键全集是合法键集合，非中文字典的多余键警告并忽略；多余调用参数导致构建失败。警告按语言与键去重，不按页面重复刷屏。
- 占位符仅支持 `{name}`，其中 name 为 ASCII 字母开头的字母、数字、下划线组合；连续两个左花括号或两个右花括号表示对应的字面花括号。非法或不配对花括号报错。只解析模板，不再次解析替换后的参数文本。

### M4. 页面上下文

页面渲染接收明确的语言上下文，统一提供当前界面语言、文案查找与格式化、语言化路由。组件不散落中英文判断，不依赖全局可变的“当前语言”。

当前界面语言与实际内容语言分开记录：英文页面回退中文正文或中文文案时，不改变其英文导航路径和语言偏好。不同语言连续生成时不能串用字典、标题或链接。

浏览器不负责批量替换页面文案。完整页面在构建后即可阅读，脚本只承担入口语言选择、偏好保存及原有交互。

## Boundaries, errors and compatibility

- 不引入前端 i18n 框架或运行时翻译服务。
- 中文基础字典不意味着默认入口改成中文；默认仍为英文。
- 字典回退不改变 [内容选择规则](content-localization.md)：有英文内容时，缺少第三种语言的内容仍优先回退英文。
- 本次保留现有数字和日期格式，不新增复数语法或 RTL 布局支持；后续若需要这些能力另行扩展，不承诺仅添加字典就覆盖所有语言排版。
- 语言注册增加 `language`、可选 `script`、`match-default`（默认 false），用于入口匹配；每个 language/script 组合最多一个默认匹配项。初始英文为 `en`，中文为 `zh`/`Hans`，两者均设为各自组的默认项。全名 name 用于切换器；提示文案所需的语言名称由 `languageNames.<locale>` 字典键提供，例如中文值“英语”“中文”，不能把原生名 English 与“语”机械拼接。
- 参数转义、格式错误需要显式错误；不能静默吞掉错误并输出空字符串。

## Acceptance scenarios

- **M-A1 默认与基础分离：** 配置 default 为英文、base 为中文；无匹配浏览器语言时根入口进入英文，而英文缺少导航文案时显示中文导航文字，链接仍指向英文路径。
- **M-A2 非中文缺键：** 英文字典缺少 `pagination.next`，生成使用中文值并警告 `en-US` 及该键，不要求补写英文译文。
- **M-A3 基础缺键：** 页面使用的键在中文基础字典不存在，构建失败，不以英文现成值掩盖基础字典缺失。
- **M-A4 参数语序：** 基础句子使用 `{first}`、`{last}`、`{total}`，其他语言可以调整顺序，所有参数均正确替换。
- **M-A5 参数错误：** 译文删除或改名所需参数，或渲染调用缺少参数，构建失败并报告具体文案问题。
- **M-A6 内容与界面解耦：** 第三种语言缺少界面键和正文译本，有中文基础文案及英文译文时，界面键取中文、正文取英文。
- **M-A7 上下文隔离：** 先生成中文再生成英文，与相反顺序生成的相同语言页面，其文案和内部语言链接一致。
- **M-A8 转义：** 文案参数含 `<`、`&` 等字符时作为文本输出，不被解释为注入的 HTML。

- **M-A9 空英文字典：** 英文字典仅含注释或文件缺失时，所有已使用页面键回退中文且构建可成功；中文基础文件缺失时失败。
- **M-A10 转义占位符：** 字面花括号能输出；参数内容即使包含 `{page}` 也不会被二次替换；非法模板及多余调用参数在构建期报错。
