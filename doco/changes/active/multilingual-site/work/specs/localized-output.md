# 多语言输出、入口与站内路由

## Scope and current contracts

本文件是目标规格，不是现行部署契约。

变更前 assets/index.html 固定跳转 URL 路径 /home.html；`KoiroCatCafe.kt` 在根目录生成首页分页、博客、项目、关于及 RSS，文章位于 pages/blogs、pages/devlogs URL 路径下，地址由标题生成。[build_site.py](../../../../../../scripts/build_site.py) 验证这些固定输出；共享图片输出到 images 目录。实际生成方式以源码和[部署文档](../../../../../../docs/deployment.md) 为基线。

[当前架构](../../../../../architecture.md)尚未记录这些边界，当前 specs 尚无相关条目。本规格不改变静态托管方式，不引入服务端语言协商。

## Requirements

### O1. 输出布局

所有站内生成页面和 RSS 按已启用语言分目录；根入口负责语言选择：

```text
dist/
  index.html
  en-US/
    home.html
    home-2.html
    blogs.html
    portfolio.html
    about.html
    rss.xml
    pages/
      blogs/<id>.html
      devlogs/<id>.html
  zh-CN/
    home.html
    home-2.html
    blogs.html
    portfolio.html
    about.html
    rss.xml
    pages/
      blogs/<id>.html
      devlogs/<id>.html
  assets/...
  images/...
  pkg/...
```

分页按实际需要生成，不强制存在 `home-2.html`。静态托管所需的根文件以及 favicon 等保持按实际用途存放；无语言差异的资源在根目录共享，不为每种语言复制一份。新附件使用 images/content/<data 相对路径>，旧图片别名保留原 images 路径；分离以避免 Windows 对 Art/art 等祖先目录的大小写合并。生成清单的路径须逐段核对真实文件名大小写。

- 每种已启用语言包含全部已发布内容对应的页面和列表。内容缺译不导致从目标语言站点隐藏。
- `id` 跨语言一致，不使用翻译标题作为地址。
- 动态继续作为首页时间线内容；项目继续在项目页展示。不因内容包有 ID 就新增详情页。
- 列表、详情、分页和 RSS 链接指向当前语言目录下对应资源，不错误地退回旧根路径。
- 每种语言链接到自己的 `rss.xml`；RSS 仍以现有博客文章范围为基础，不把本次语言改造扩大为新增动态或开发日志订阅。
- RSS 与页面使用相同的内容选择结果，并在摘要中提供必要的缺译与 AI 翻译声明。

### O2. 回退页面是完整静态副本

内容选择遵循 [内容规格](content-localization.md)，在构建时确定。

缺少目标译本时，在目标语言路径下生成可直接打开的完整 HTML，不让读者先加载空页再请求另一种语言正文，也不跳转到英文或中文页面。

复用实际译本正文，按目标语言上下文渲染页面外壳，而不是逐字节复制源语言整页：

- 导航、分页、RSS 和语言入口属于目标语言。
- 标题、摘要和正文来自所选译本。
- 缺译提示说明目标语言不可用及实际正文语言。
- HTML 文档语言表示目标界面语言；正文区域明确标记实际内容语言。字典中的中文回退不伪装成英文译文。
- AI 翻译声明取自实际译本，不取自缺失的目标文件。

回退副本不能被声明为一个实际存在的目标译本。设计采用：真实译本详情页 canonical 指向自身，并互相声明真实已发布译本的 hreflang；回退详情页 canonical 指向实际译本的详情地址，标记 `noindex,follow`，不作为目标语言的 hreflang 候选。列表页 canonical 指向自身并可关联各语言列表，不因部分条目缺译而整页 noindex。旧地址跳转页同样 noindex。

### O3. 根入口选择

访问 URL 路径 /index.html（或站点根入口）时，按以下顺序选择目标语言：

1. 有效且仍受支持的已保存用户偏好。
2. 浏览器通过 `navigator.languages` 提供的语言偏好。
3. 默认语言 `en-US`。

浏览器语言作为系统语言偏好的可用信号，不要求读取浏览器无法访问的操作系统设置。

按 `navigator.languages` 的优先顺序逐项匹配，每个候选先精确匹配规范化标识，再匹配同 language/script 的注册默认项；无默认项则只有唯一匹配项时才采用。使用 `Intl.Locale` 规范化并推导 script（可用时 maximize），如 `en-GB → en-US`、`zh-SG → zh-CN`。显式或推导为 Hant 的繁体中文不能匹配 Hans 简体中文；继续下一候选，最终回退默认英文。浏览器不支持 Intl.Locale 时仍做精确匹配，英文 language-only 匹配允许，其他含地区/文字体系的模糊匹配保守跳过。`navigator.languages` 不可用时尝试 `navigator.language`，仍不可用则默认英文。

失效或不受支持的保存值不能生成非法 URL，应继续浏览器语言或默认值选择。偏好存储不可用时，语言选择仍可继续，不能让入口失效。

自动选择仅发生于根入口；直接访问 /zh-CN/...、/en-US/... 等语言 URL 时尊重明确地址，不因保存偏好或系统语言进行二次重定向。

禁用 JavaScript 时，根入口提供可用的普通语言链接或英文首页入口，不留下无法进入网站的空白页。此项是入口的降级要求，不要求在无脚本环境自动检测语言。

### O4. 手动切换语言

- 切换器展示已启用语言的可读名称，使用普通链接；无脚本时仍能导航。
- 有脚本时用 localStorage 的 `koiro.site.locale` 保存用户主动选择，值必须为已注册规范语言标识。读写失败不阻止普通链接导航。
- 切换语言时进入对应的同一页面；文章使用同一 ID，不将文章切换操作送回首页。
- 目标译本缺失仍可进入对应语言的回退副本，不能据此隐藏全站语言选项。
- 主页、博客、项目和关于页切换后保持页面类型与页码；所有语言共享发布集合、排序和分页，因此相同页码必然可用。保留稳定动态/项目锚点；文章翻译的段落结构可能不同，不承诺跨语言保持标题锚点。
- 仅访问明确语言 URL 不自动等价于修改用户已保存的主动偏好；本轮不增加独立的正文语言偏好开关。

### O5. 侧边栏语言入口视觉定稿

- 图标行位于头像与个人简介下方，水平居中；不放在底部导航下方，不修改原侧边栏底部留白。
- 简介到图标行的布局间距为 4px，三个按钮之间的 gap 为 4px。按钮命中区域为 34 × 34px，SVG 为 19 × 19px；图标行底部保留 16px。
- 顺序为 GitHub、itch.io、语言。GitHub 指向 `https://github.com/gloridifice`，itch.io 指向 `https://gloridifice.itch.io/`。
- 三个按钮无背景、无边框，默认使用弱色 `--text-color-2`，悬停与展开时适度提亮；键盘焦点保留可见标识。
- 三个 SVG 均为空心、圆角描边。itch.io 使用店铺与手柄意象的描边版本，不使用实心品牌图形；GitHub 描边为 2.2，itch.io 与语言为 1.7（24 × 24 viewBox），平衡视觉重量。
- 语言图标使用既定 Languages 图形，后续 AI 翻译与缺译提示复用相同图形。
- 点击语言图标在按钮附近打开浮窗，不跳转到独立设置页，不挤动页面布局。浮窗列出语言名称、语言代码和当前选中标记；点击外部或 Escape 关闭，支持键盘操作，窄屏不超出视口。
- 以上效果已通过 dist-only 视觉预览确认，尚未进入正式生成器。预览的模拟选择不等于正式语言切换实现。

## Boundaries, errors and compatibility

- 执行时按本规格迁移，不能将 dist-only 预览脚本的模拟状态带入正式输出。
- 兼容设计：旧 URL /home.html、/home-N.html、/blogs.html、/portfolio.html、/about.html 及迁移前已发布的标题文章地址生成指向对应中文页面的静态跳转页，并提供普通链接；不根据偏好把旧中文文章链接改跳英文。别名暂不设过期时间，不在本次变更中删除。片段可保留到对应中文页面。
- 根 URL /rss.xml 保留为中文 RSS 的实际 XML 副本，不能替换为 HTML 跳转。历史图片输出路径通过迁移清单生成共享资源别名，避免已传播的图片地址失效。迁移与兼容清单见 [迁移规格](data-migration.md)。
- 新语言目录必须参与最终产物校验；将来实现时需覆盖各语言页面、RSS 和本地资源引用，而不是只检查旧根页面。
- 不在客户端判断文章回退，不向外部翻译服务发起请求，不依赖运行时网络来读取译本。
- 共享资源及媒体复制遵守现有内容根边界，不允许语言目录改造产生越界引用。
- RSS channel 语言应描述目标订阅语言；遇到回退正文需显式说明实际语言，不能以 channel 标识隐瞒缺译。

## Acceptance scenarios

- **O-A1 完整语言站点：** 启用中英文、内容只有中文，构建仍输出两套首页、博客、项目、关于、相关详情和各自 RSS，英文内容页显示中文回退提示。
- **O-A2 链接闭合：** 打开英文文章，其导航、列表返回链接和 RSS 入口均在英文目录；图片和样式可复用根资源。
- **O-A3 可独立阅读：** 禁用脚本直接访问英文回退文章，正文和提示仍完整显示，不要求跳转或额外请求正文。
- **O-A4 保存偏好优先：** 保存中文偏好、浏览器偏好英文，访问根入口进入中文首页。
- **O-A5 浏览器匹配：** 没有有效保存偏好，浏览器提供 `zh-CN` 时进入中文；仅提供 `en-GB` 时可以匹配英文；没有可匹配语言时进入英文。
- **O-A6 无效偏好：** 保存的语言已被移除，根入口忽略它并继续选择受支持语言，不导航至不存在的语言目录。
- **O-A7 明确地址优先：** 保存英文偏好，但直接访问中文文章，页面保持中文地址，不自动重定向。
- **O-A8 手动切换：** 在中文文章切换英文，进入同 ID 的英文文章；不存在英文译本时显示英文路径下的中文回退页面，并记录英文偏好。
- **O-A9 无脚本与存储受限：** 普通语言链接仍能使用；有脚本但偏好存储不可用时，入口仍可按浏览器语言或英文默认值进入站点。
- **O-A10 RSS 一致性：** 英文 RSS 中的文章链接指向英文目录；英文译本缺失时，摘要与英文回退页面使用同一中文内容并注明缺译，不把不同译本重复计入 feed。

- **O-A11 侧边栏视觉：** 桌面和手机下图标行均位于简介下方，布局间距和按钮 gap 为 4px；三个图标弱色无底框，itch.io 为空心描边，GitHub 视觉粗细与其他图标接近。点击语言后浮窗不改变导航位置。

- **O-A12 旧链接兼容：** 旧中文文章地址跳转对应中文稳定 ID 地址，原有资源链接可访问；根 RSS 仍可由 XML 解析器读取，不受浏览器偏好影响。
- **O-A13 搜索索引：** 英文回退中文的详情页 noindex 且 canonical 指向中文详情，不声称存在英文译本；真实英文译本加入后，英文详情恢复 self-canonical 并参与真实译本 hreflang。
- **O-A14 语言匹配边界：** `[fr-FR, zh-CN]` 选择中文；`[en-GB, zh-CN]` 选择英文；只有 `zh-TW` 且没有 Hant 语言时不匹配简体中文，最终默认英文；非法已保存值被忽略。
