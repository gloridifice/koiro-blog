# multilingual-site

## Purpose

为博客增加可扩展的语言系统，同时支持页面文案和内容译本。首批语言为 `zh-CN`、`en-US`，后续新增语言不应要求逐个修改页面组件。

当前站点由 Kotlin 解析带 TOML 头部的 Markdown，生成静态 HTML 和 RSS。一个 Markdown 文件被视为一条独立内容；页面文案多为硬编码中文；博文和开发日志地址由标题生成。直接增加翻译文件会造成重复收录、地址随标题变化，也无法说明缺译和 AI 翻译状态。

本变更经过需求讨论、dist-only 视觉预览和完整设计后，已获授权执行。实际交付的架构和契约已同步到当前文档，验证证据保留在工作包；不以设计文档的机械通过代替实现验收。

## Scope and acceptance

### 目标范围

- 保留静态站点生成方式，在构建时完成语言选择、译本回退、HTML 和 RSS 生成。
- 支持博文、开发日志、动态和项目的本地化；动态仍在首页时间线展示，不增加独立详情页。
- 内容按文件夹组织：meta.toml 保存公共元数据，各语言 Markdown 保存标题、摘要、正文和译本属性，图片保存在内容包中。
- 迁移时将内容文件夹改为有语义的英文 snake_case，例如 `kotlin_jvm_static_blog`；初始稳定 ID 与文件夹名一致。语言文件名、语言配置和语言目录统一使用 `zh-CN`、`en-US`，不能误改为 snake_case。
- 使用稳定内容 ID 关联译本和生成 URL，后续标题及目录改名不重算 ID；现有表示摘要的 slug 改为 summary。
- 中文版本作为发布基线。已发布内容必须有可用中文版本；目标译本缺失时优先英文，否则中文。英文缺失不阻止构建。
- 每个语言目录生成完整页面和自己的 RSS；回退页面保留目标语言外壳，正文使用实际译本，并注明缺译和正文语言。
- 每个译本支持布尔 `ai-translation`，省略为 false；此字段表示 AI 翻译而不是 AI 创作，提示跟随实际显示的译本。
- 页面使用 TOML 字典和构建期渲染；中文为基础字典，非中文缺键回退中文并警告。默认访问语言仍为英文。
- 根 index.html 按有效已保存偏好、浏览器语言、英文默认值选择首页；明确语言 URL 不自动跳转，手动切换保留页面身份。
- 共享无语言差异的图片、样式和 Wasm 等静态资源，不按语言重复制作资源副本。

### 已确认的界面

侧边栏图标行位于头像与简介下方，居中排列 GitHub、itch.io、语言图标；简介间距和按钮 gap 均为 4px。图标无背景无边框、使用弱色；itch.io 为空心描边，GitHub 加粗以平衡视觉重量。语言按钮就近展开选择浮窗，点击外部或 Escape 关闭。

首页文章卡片在右下角显示翻译图标；动态在正文末尾显示普通提示行。文章详情提示放在完整标题信息框外下方左侧、正文之前，不插在 h1 与日期之间。AI 翻译图标及文字使用弱灰色；缺译图标及整行文字统一为黄色 `#c5a35b`，不使用有背景的提示框。

### 实现设计补全

以下作为执行审阅的明确方案，不伪称已上线：

- ID 使用英文 snake_case，同类型内全局唯一；完整映射覆盖当前 41 个 Markdown，包括草稿和模板。资源哈希保持，未知历史字段保留，代码块示例不改。
- 迁移器默认 dry-run，显式 apply，临时构造、校验和备份后才替换 data；重复执行不重复迁移。
- 保留旧根页面及旧标题文章地址的中文跳转、根中文 RSS 的实际 XML 和旧图片地址；不在此次迁移中删除旧入口。
- 用 localStorage 保存主动偏好；浏览器语言匹配保守区分 script，不能把繁体中文无条件匹配简体中文。
- 各语言共享发布集合和页码；动态与项目有稳定锚点。所有生成页面通过输出清单安全清理过期产物。
- 真实译本参与 canonical/hreflang；回退详情页 canonical 指向实际译本并 noindex，不能虚构目标译本。
- 同时缺译且实际译本为 AI 翻译时，卡片黄色图标优先且说明包含两种状态；动态/详情依次显示黄色回退行、灰色 AI 行。不额外增加原文按钮，可通过语言入口访问中文内容。

### 执行交付边界

用户已授权实施。本次执行正式生成器、页面控件、数据迁移、兼容输出、测试及当前文档更新；不自动提交、远程发布或执行 doco complete/archive，变更保持 active。

本次暂不翻译英文页面文案或文章：提取完整中文字典、提供空英文字典、将现有内容迁为中文包，英文站依靠回退即可完整生成。英文 snake_case 命名不是英文正文翻译授权。

### 不在本变更范围内

运行时机器翻译、翻译 API、全量英文译文、RTL 排版、复数框架、日期格式国际化、译文过期检查、人工审校标记，以及独立于界面语言的正文偏好设置。保留现有日期展示与 Markdown/图片行为，不借机重写无关渲染逻辑。

### 目标验收

1. 同一内容的多语言文件按一篇计数，各语言共享原始日期、稳定排序和分页，项目关联不因翻译名称变化而断开。
2. 目标/英文/中文选择覆盖缺失、草稿和 AI 标记；发布内容缺中文基线时报错，缺英文不报错。
3. 内容包目录及初始 ID 为英文 snake_case，语言文件仍为连字符形式；原文文字和媒体哈希保留，必要的资源与文章互链正确迁移。
4. 各语言页面、RSS、导航与资源引用闭合；旧中文地址和根 RSS 继续可用；增量构建不会留下过期译本、语言或分页产物。
5. 中文基础键、参数和配置错误导致构建失败；空英文文案回退中文，输出去重警告。
6. 根入口和语言浮窗支持已保存偏好、浏览器匹配、明确语言 URL、键盘操作、窄屏及无脚本降级。
7. 已确认的侧边栏、卡片、动态及详情声明位置/颜色由正式生成器输出，不依赖 dist 预览脚本或模拟查询参数。
8. 真实译本与回退副本的语言及 SEO 元信息准确；RSS/XML 转义正确；不将回退页面宣传为真实翻译。
9. 当前架构、规格和使用文档只在实际交付后同步；测试保护真实输出和迁移恢复边界，不以源码匹配代替验收。
