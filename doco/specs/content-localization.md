# 内容包与译本

## 格式

每篇内容在 data 的 blogs、devlogs、actives 或 portfolio 下有一个内容包。包目录为英文 snake_case，可置于分类子目录中；含 meta.toml、zh-CN.md、可选其他语言文件和附件。语言文件统一使用规范连字符标识，如 en-US.md，不使用下划线。

公共 ID 使用 `[a-z][a-z0-9]*(?:_[a-z0-9]+)*`，禁止 Windows 设备名，同类型内唯一。初始包目录名与 ID 相同；标题或目录改名不重算 ID。分类目录不参与 URL，也不替代 class 字段。

## 元数据

meta.toml 的 id、published 必填。按类型另外要求：

| 类型 | 必填公共字段 | 可选公共字段 |
|---|---|---|
| 博文 | date、class | tags（默认空）、icon、emoji |
| 开发日志 | date、work、index | preview |
| 动态 | date | 无额外要求 |
| 项目 | project、url、preview、status、type、lite | date（展示字符串） |

语言文件以 fenced TOML 头部开始，再跟正文。title 为本语言标题，summary 为博文摘要，description 为项目简介，preview 可覆盖公共封面。published 默认 true，ai-translation 为严格布尔值、默认 false。发布的博文/开发日志要求非空标题，项目要求标题及简介。动态允许空头部。

历史附加字段保留在源文件中，未识别字段会警告；不会作为内容列表的额外维度。work/project 保持稳定关联值，允许开发日志关联一个尚未列入作品集的项目。

## 发布和选择

- 公共 published=false 时，不生成该内容的页面、列表项或 RSS 条目。
- 已发布内容必须有可用中文译本，否则构建报错。草稿可以缺中文，但已有元数据仍校验。
- 对每个语言按“目标语言 → en-US → zh-CN”去重查找；缺失或 published=false 的译本不可用。
- 标题、摘要、正文、图片说明、封面覆盖和 AI 状态来自同一译本，不能逐字段混用。
- 同一内容只计一次，使用公共日期排序；所有语言共享发布集合与页码，新增译本不更改发布日期。
- 选择在构建期完成，回退页面是目标语言目录下可直接阅读的完整 HTML。

## 翻译声明

复用侧边栏 Languages 空心图标，不使用有背景的提示框。

| 场景 | 位置与形式 |
|---|---|
| 卡片 AI 翻译 | 右下角弱灰色图标，title 和可访问说明包含 AI 状态及实际语言 |
| 卡片缺译 | 同位置黄色图标，说明包含目标与回退语言 |
| 动态 | 正文末尾的普通行，AI 文案“本动态由 AI 自动翻译为英语。”；缺译文案“本动态无英语，自动回退到中文。” |
| 文章详情 | 完整 page_description 信息框外、下方左侧，正文之前；主语改为“本文章” |
| 项目 | 简介末尾普通行，主语为“本项目简介” |
| RSS | 在摘要中以文字说明状态 |

AI 行的文字与图标使用 `--text-color-2`，缺译行的文字与图标均为 `#c5a35b`。图标 16px，文字 12px，gap 7px，窄屏可换行。详情提示相对框外左边缘内缩 20px。卡片图标距右侧 14px、底部 12px，不能遮挡摘要、分类或日期。

缺译和 AI 翻译可同时发生：卡片显示一个黄色图标，说明包含两种状态；行提示先黄色回退、后灰色 AI。ai-translation 不表示 AI 创作；false 也不证明是人工翻译。

中文原文通过语言切换器访问，不额外添加原文按钮；动态与项目使用稳定锚点，见 [输出契约](localized-output.md)。

## 资源与错误

资源相对于实际语言文件或公共 meta.toml 解析，限制在内容根内；重复 ID、坏字段、坏图标或已发布内容缺中文时报出源路径并失败。非法输入不能静默跳过。构建不修改源正文或自动翻译。附件源字节在迁移中保持，构建输出仍按已有图片压缩规则处理。
