# 多语言输出与浏览器选择

## 目录与路由

index.html 为生成的根入口。每个已启用语言目录包含 home.html、按需的 home-N.html、blogs.html、portfolio.html、about.html、rss.xml，以及 pages/blogs/<id>.html、pages/devlogs/<id>.html。assets、images、pkg 等无语言差异资源在根目录共享。新附件位于 images/content/<data 相对路径>，历史图片别名保留原 images 路径；分开命名空间，避免 Art/art 等目录在 Windows 被合并而导致 Linux 托管断链。

所有语言共享当前构建的内容集合、排序及分页。默认调试构建包含公共 published=false 的内容，`--release` 构建仅含 published=true 的内容。相同日期按内容类型、ID 作确定性排序。动态没有详情页，使用所属主页页码与 `active-<id>` 锚点；项目使用 portfolio.html 的 `project-<id>` 锚点。

站内导航、分页、文章链接和 feed 入口属于当前语言。相对 Markdown 文章链接按内容包索引转为当前语言地址，显式语言 URL 和外链不改。无效文章目标失败，不生成断链；调试构建允许链接草稿，release 构建拒绝链接被排除的草稿。

## 入口与偏好

根入口用静态 site-language.js 选择语言：有效 localStorage 偏好 `koiro.site.locale` → navigator.languages（不可用时 navigator.language）→ en-US。直接语言地址不自动重定向，也不因访问而隐式改写主动偏好。

按浏览器候选顺序逐项精确匹配，再匹配同 language/script 的默认项；没有默认项时只采用唯一候选。Intl.Locale 推导 script，en-GB 可选 en-US，zh-SG 可选 zh-CN，Hant 不匹配 Hans。无 Intl.Locale 时保守匹配，仅保留精确匹配及英文同语言匹配。

语言选项为普通链接；手动点击尝试保存偏好，存储失败仍能导航。切换保留页面类型、主页页码及稳定动态/项目锚点；不承诺不同译本的标题段落锚点相同。禁用 JS 时根入口仍有普通语言链接，页面正文与回退声明可直接阅读。

## 侧边栏

头像和简介下方居中排列 GitHub、itch.io、语言图标。简介外边距为 `24px 0 10px`，按钮 gap 为 4px，命中区 34px、SVG 19px，图标行底部留白 16px。默认弱色、无底框；itch 为描边店铺/手柄，GitHub 描边 2.2，其余 1.7。键盘焦点可见。

侧边栏的游戏作品和博客仓库外链按钮内部文字保持单行；两按钮总宽度超出容器时，上下排列并分别居中。换排依据实际内容与容器宽度，不以固定视口断点强制切换。

语言按钮就近展开 popover，不挤动布局；显示名称、语言代码、当前标记。支持键盘、Escape、外部点击、滚动/缩放重新定位；窄屏不溢出。无 JS 或无 popover 支持时显示普通语言链接。

## 文章目录

详情页的 Preview Rail 位于左侧，站点导航位于右侧；不改变正文宽度。目录仅在视口至少 1200px 且支持精细指针悬停时显示；较窄布局改用正文顶部的站点导航，手机端不提供目录。目录脚本未初始化或文章没有标题时不显示 rail。

目录只收录正文 Markdown 标题，不包含页面文章大标题。ATX H1–H6 和 Setext 标题均有唯一锚点，沿用 `heading<级别>_<从零计数>` 格式。标题挂在前面最近的较浅标题下，跳级不补空节点；按实际树深度展示前三层。更深标题仍属于最近的可见目录祖先。标题文字使用实际正文语言，导航名称使用页面界面语言。

收起时仅显示左端对齐的一级短横条；悬停后显示全部一级文字，在当前项右侧展开二级列表，再悬停二级项展开其三级列表。每列按内容自然宽度布局，最大 280px，同时保证三列不越出视口；超长标题省略，完整名称保留在链接的可访问名称中。目录列及链接行无背景、边框、阴影或毛玻璃；仅二、三级标题文字有 80% 不透明度的 `--bg-color-0` 底色、上下 2px / 左右 6px 内边距及 4px 圆角；一级标题文字及横条不带底框，各行间距为 28px。悬停改变横条长度、文字颜色和显隐。长列表各自滚动，隐藏目录滚动条但保留滚轮和键盘滚动；跨列移动保持预览，离开整个区域延迟收起。

各级条目都是原生片段链接，支持点击、Enter、历史记录和复制链接。滚动正文更新当前章节及其一级横条，不强制展开预览。键盘支持 Tab、上下移动、右键进入子列、左键返回父项、Home/End 和 Escape 收起；隐藏子列前将仍在其中的焦点移回一级项。减少动画偏好关闭过渡和顺滑滚动。

`npm run test:toc` 使用临时内容及真实 Kotlin 生成器、Sass 和 Playwright 浏览器验证层级、跨列悬停、标题宽度、锚点、滚动跟踪、键盘、长列表与手机隐藏；不修改正式内容，也不依赖 Wasm。可用 `BROWSER_CHANNEL=msedge` 或 `chrome` 选择本机浏览器。

## 回退与索引

回退页面保留目标界面语言和路径，正文标记实际语言。详情真实译本 self-canonical 并互相声明已发布真实译本的 hreflang；缺译详情 noindex,follow，canonical 指向实际译本，不伪造目标语言的 hreflang。混合列表 self-canonical，不因条目缺译而整页 noindex。

每语言 RSS 仍只收录博文，链接指向该语言目录，摘要与页面使用相同译本并注明状态。XML 字符正确转义，feed 日期为 RFC 1123；无时区源日期按 Asia/Shanghai 解释。根 rss.xml 为中文 feed 的实际 XML 副本。

## 兼容与增量构建

旧根入口与旧标题文章地址保留中文静态跳转及普通链接，保留中文片段，不按偏好改跳英文；跳转页 noindex。若旧地址映射的内容缺失或因元数据错误被跳过，则警告并不生成对应跳转，成功构建后清理其旧产物。旧图片由 data/migration-map.toml 维持，附件别名独立于文章是否被跳过；无法按内容身份重定位时使用清单原始 source，仍校验资源存在及路径安全。别名暂不自动过期。

生成器维护包含附件的输出清单，只删除清单内不再需要的文件，拒绝越界路径、符号链接及大小写冲突；直接运行生成器不批量删除无关手写文件。`npm run build` 保留登记产物及增量缓存，删除未登记的旧文件，重拷非图片静态输入；成功生成后清理过期登记产物。仍全量校验全部语言页面、RSS、站内链接、资源和兼容入口，并逐段核对生成清单路径的实际大小写；缓存不能绕过输入/产物安全校验。

增量仅适用于以下原子资源：

| 原子 | 更新边界 |
|---|---|
| 文章 HTML | 一篇博文或开发日志的所有已启用语言一起判断、一起生成；任一语言产物缺失或状态改变时重建整组 |
| 图片及附件 | 每个源附件独立判断；历史图片别名独立判断并沿用原格式转换规则；静态图片同样按文件复用 |
| RSS 文章 | 单篇博文的各语言 item 一起缓存；不含 feed 的当前构建时间 |

首页、分页、博客列表、作品集、关于页、根入口、兼容 HTML 跳转及各语言完整 RSS（含根中文副本）均每次全量生成和写入。RSS 的 lastBuildDate 仍取当前构建时间。

原子缓存必须匹配当前输入指纹及全部输出状态。文章指纹覆盖公共 metadata、全部译本、字典、生成代码、路由和构建模式；附件依赖变化也会使文章失效。命中时仍恢复附件依赖并修复缺失的图片输出，不能因跳过文章渲染而删除其图片。图片按源修改时间、大小和独立图片处理指纹判定，不保证识别同时保留时间戳与大小的内容改写。处理指纹包含 ImageAssets、ImageCompressor 及其嵌套类字节码、Thumbnailator 依赖和 JDK 运行时信息；无关的页面模板、元数据解析、路由代码或其他依赖变化不使图片及历史图片别名失效。编译目录与打包 JAR 使用相同的类族边界，不以整站输出目录、整站 JAR 或全局 classpath 作为图片处理版本。图片处理代码或相关依赖、运行时变化时仍重建；源或产物状态变化、产物缺失时仍更新或修复。切换到独立指纹后的首次构建会重建一次图片缓存。

Kotlin 缓存为 `.incremental-site.json`，RSS item 作为私有片段保存在其中，不额外生成公开 item 页面。静态图片状态由 `.static-image-cache.json` 记录。缓存缺失、不可解析或版本不兼容时执行冷生成；缓存中的越界路径及符号链接仍须拒绝。缓存与清单在 Kotlin 页面生成成功后更新，失败时不提交 HTML/RSS 或清理旧产物；附件可能提前写入。debug/release 切换、内容/语言删除后只保留本次需要的原子及产物，兼容清单仍引用的图片不视为过期。删除整个 dist 可强制全部重新生成。
