# 页面文案

## 配置

i18n/locales.toml 注册语言：default 为 en-US，base 为 zh-CN，content-fallbacks 为 `["en-US", "zh-CN"]`。每个语言配置 name、language、可选 script 和 match-default。同 language/script 组合最多一个默认匹配项。标识必须规范化且唯一。

每语言文案在同名 TOML 文件中，按语义分组。中文是全部合法键及命名参数的基准，不意味着默认访问中文。当前 en-US.toml 已提供全部基础键的英文翻译，并保持与中文一致的命名参数集合。

## 查找与模板

- 文案按目标键、中文键查找，不经过英文中转；正文采用独立的译本选择规则。
- 中文缺少被使用的键、基础文件缺失、TOML 格式错误或文案不是字符串时构建失败。
- 非中文字典缺失视为空字典；缺键回退中文并按语言/键去重警告。未知译文键警告，不可绕过中文基准直接使用。
- 使用完整句子与 `{name}` 参数。name 为 ASCII 字母开头的字母、数字、下划线；连续两个左/右花括号表示字面花括号。
- 参数集合必须与中文一致；缺参数、多余参数、不成对花括号或非法名字时报错。替换一次，不重新解析参数内容。
- 字典是普通文本，由 kotlinx.html 转义；不能用任意 HTML 代替文案。真实文案语言通过可用的文本容器 lang 表示，属性文案不嵌标签。

## 内容边界

导航、分页、按钮、无障碍名称、首页与关于介绍、分类名称、RSS 描述及翻译提示均来自字典。文章标题、摘要、正文、项目简介、图片说明仍属于语言 Markdown。友链专名保留，友链描述按稳定标识进入字典。

提示所用语言名称取 languageNames 对应键，如“英语”“中文”；不得机械追加“语”。日期与数字保留现有格式，不提供复数模板或 RTL 布局框架。

## 渲染上下文

PageContext 显式携带界面语言、页面身份、文案及路由。不得使用全局可变 locale。英文界面回退中文文字或正文，不改变英文路径与用户偏好。浏览器不负责批量替换页面文本。
